# Optic branding

`logo.png` is the transparent application logo. `icon.ico` and `icon.icns` are desktop icon conversions generated with electron-builder's icon converter.

The user-provided artwork was edited using the built-in image generation tool with `transparent_background: true`. Its PNG alpha channel was verified; the square canvas is 1254 × 1254 pixels.

Edit prompt:

> Use case: background-extraction. Edit target: the supplied application logo. Remove the dark rectangular backdrop, background grid and detached floating binary digits/particles. Preserve the central cyan/blue/green ship-wheel and camera-aperture emblem, its geometry, shading, wireframe right half and colors. Clean alpha-transparent cutout, including background visible through open gaps. Center the entire emblem on a square transparent canvas with small even padding for desktop application icons. No new text, no added elements, no opaque background. Save the transparent PNG for the project.

The internal application ID, Kubernetes field-manager identifier and WORKBENCH environment variables retain their previous values for compatibility. The product, executable and displayed application name are Optic.
